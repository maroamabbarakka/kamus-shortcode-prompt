# Kamus Shortcode Prompt Pro (Visual Library & Prompt Studio)

Aplikasi web pustaka visual interaktif, ensiklopedia shortcode, dan generator prompt profesional untuk kreator AI, desainer produk, rekayasawan prompt (prompt engineers), dan sutradara video. Mengorganisasi **2.588+ shortcode prompt multimodal** (Image, Video, Hybrid, Content & System Directives) dan **47 lembar poster referensi infografis beresolusi tinggi** dalam antarmuka yang bersih, elegan, dan siap produksi.

---

## 🌟 Fitur Utama

1. **Desain Bersih & Elegan (Clean Light & Glassmorphism Theme)**:
   - Antarmuka bertaraf internasional yang cerah, bebas penumpukan teks (*zero text clutter*), tipografi tajam, dan kenyamanan visual maksimal.
2. **47 Lembar Poster Referensi Infografis Interaktif**:
   - Menampilkan poster visual resolusi tinggi dengan kemampuan zoom, inspeksi kode, dan salin instan untuk seluruh 47 kelompok referensi industri (termasuk 32 infografis baru dari koleksi *Prompt Baru*).
3. **Live Subject Replacer (Ketik Subjek Langsung)**:
   - Ubah subjek default menjadi produk Anda (misal: *Kopi Espresso Dingin*, *Sepatu Sneakers*, *YBS FUTSAL CLUB*) langsung di dalam modal detail, dan seluruh prompt siap pakai akan diperbarui secara real-time.
4. **Kamus Lengkap (2.580+ Shortcode Explorer)**:
   - Akses pencarian kilat (tekan tombol `/`), filter media (Image, Video, Hybrid, Content), filter keluarga fungsi, dan paginasi responsif berkecepatan tinggi.
5. **Dukungan Sintaks Lanjutan & Bracket Templates**:
   - Mendukung format slash command (`/`), Gemini engine directive (`/G`), ChatGPT prompt directives (`/identity_lock`, `/logic_gate`, `/code_diff`), serta template variabel dinamis bersintaks kurung siku `[brackets]`.
6. **Prompt Studio / Composer**:
   - Gabungkan beberapa shortcode sekaligus dengan preset industri (termasuk Logo & Brand Identity Studio), pemilihan rasio aspek (16:9, 9:16, 1:1, 4:5), durasi video, tata cahaya, dan batasan konsistensi.
7. **Responsif Mobile Native**:
   - Beradaptasi sempurna di ponsel cerdas dengan mobile topbar dan bottom navigation bar ala aplikasi iOS/Android.

## 📚 Klasifikasi Kategori & Ekosistem Prompt

Aplikasi ini mencakup seluruh spektrum rekayasa prompt kecerdasan buatan:

### 1. Advanced LLM & Reasoning Directives (ChatGPT & Gemini)
Koleksi perintah terstruktur untuk mengontrol alur penalaran model bahasa besar:
- **Identity & Context Locks**: `/identity_lock`, `/context_anchor`, `/persona_freeze` menjaga model tidak menyimpang dari peran profesionalnya.
- **Code & Logic Operations**: `/code_diff`, `/logic_gate`, `/edge_case_probe`, `/ast_verify` untuk audit kode, optimasi algoritma, dan validasi logika perangkat lunak.
- **Google Gemini System Directives**: `/G`, `/critique`, `/benchmark`, `/iterative_refine`, `/multimodal_align` untuk alur kerja multimodal Google Gemini.

### 2. Generative Visual & AI Art Engines (Midjourney, SDXL, Flux)
- **Komposisi & Sudut Kamera**: Extreme Close-Up, Drone Overhead, Dutch Angle, Worm's Eye View, Golden Ratio Grid.
- **Pencahayaan Sinematik**: Volumetric God Rays, Rim Light, Chiaroscuro, Biophilic Sunlight, Moody Cyberpunk Neon.
- **Estetika & Gaya Artistik**: Claymation, Retro Anime 90s, Risograph Print, Brutalism 3D, Vaporwave, Bauhaus, Isometric Diorama.

### 3. Motion, Video & 3D Cinema Directives (Runway, Pika, Sora, Unreal Engine)
- **Kamera Gerak Dinamis**: Pan, Tilt, Orbit 360, Vertigo Dolly Zoom, FPV Drone Sweep.
- **Penyutradaraan Efek**: Slow-Motion 120fps, Bullet Time, Hyperlapse, Fluid Dynamics, Particle FX.

### 4. Brand Identity, UI/UX & Logo Studio
- Koleksi khusus 23 shortcut prompt untuk merancang identitas jenama (brand), logo komersial, tipografi, dan *mockup* produk.

## 🎨 Shortcut Prompt Logo (Brand Identity & Logo Studio)

| Shortcut | Fungsi / Arti | Shortcut | Fungsi / Arti |
|---|---|---|---|
| `/logo` | Buat konsep logo | `/bold` | Logo tegas dan kuat |

| `/minimal` | Logo minimalis | `/wordmark` | Logo berbasis tulisan |
| `/modern` | Logo modern | `/monogram` | Logo inisial |
| `/premium` | Logo mewah/premium | `/color` | Tentukan kombinasi warna |
| `/3d` | Logo dengan efek 3D | `/font` | Rekomendasi gaya tipografi |
| `/badge` | Logo emblem/badge | `/mockup` | Tampilkan pada mockup |
| `/mascot` | Logo maskot | `/print` | Siapkan konsep untuk produksi/cetak |
| `/sport` | Logo olahraga | `/vector` | Konsep logo bergaya vector |
| `/esport` | Logo gaming/esport | `/negative` | Buat negative prompt |
| `/luxury` | Logo elegan/luxury | `/5opsi` | Buat 5 opsi konsep berbeda |

### 🔥 Contoh Penggunaan
- `/logo /sport /bold /3d — YBS FUTSAL CLUB`
- `/logo /premium /minimal /monogram — MDS STEEL`
- Workflow Cepat: `/logo /brand /style /icon /color /font /mockup /negative`

## 🚀 Cara Menjalankan Secara Online (GitHub Pages)

Proyek ini dibangun murni dengan teknologi web statis (*zero dependencies*), sehingga dapat langsung di-hosting di **GitHub Pages** atau server statis mana pun:

1. Buka repositori ini di GitHub.
2. Masuk ke menu **Settings** > **Pages**.
3. Pada bagian **Build and deployment > Source**, pilih **Deploy from a branch**.
4. Pilih branch **`main`** dan folder **`/ (root)`**, lalu klik **Save**.
5. Situs web interaktif Anda akan langsung aktif secara publik!

## 📁 Struktur Berkas

- `index.html` : Halaman aplikasi utama (dilengkapi modal interaktif & search bar terintegrasi).

- `kamus-data-v4.js` : Basis data asli 1.322 entri shortcode multimodal.
- `prompt-baru-data.js` : Basis data ekspansi 1.242 entri shortcode terstruktur dan 32 spesifikasi kartu poster referensi (`ref-15` s.d `ref-46`).
- `assets/references/` : Berisi 47 berkas gambar poster referensi infografis asli (`ref-0.jpg` hingga `ref-46.jpg`).
- `assets/` : Gambar thumbnail visual tematik untuk kartu grid.
- `kamus-shortcode-prompt-data-v4.json` : Master dataset lengkap v4 (2.588 entri shortcode terstruktur) format JSON.
- `kamus-shortcode-prompt-data-v4.csv` : Master dataset lengkap v4 (2.588 entri shortcode terstruktur) format CSV.
- `kamus-shortcode-prompt-data-v3.json` : Master dataset v3 legacy (1.322 entri) format JSON.
- `kamus-shortcode-prompt-data-v3.csv` : Master dataset v3 legacy (1.322 entri) format CSV.
